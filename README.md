# CodingSavvy GRE Theme

A GRE preparation platform with a custom theme, built with Next.js.

## Overview

A comprehensive GRE prep portal featuring practice questions, placement portal integration, and a custom-designed theme. Built as a learning platform for students preparing for the GRE.

## Features

- **Practice questions** with categories
- **Placement portal** integration
- **Custom theme** with animations
- **Responsive design**
- **Hero section** with call-to-action

## Tech Stack

- **Framework:** Next.js with Turbopack
- **Language:** TypeScript
- **Styling:** TailwindCSS, PostCSS
- **Components:** Custom UI components

## Getting Started

```bash
npm install
npm run dev
```
